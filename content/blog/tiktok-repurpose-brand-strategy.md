## The Concept

After the earlier rebrand work for the PDC account, a new opportunity emerged: **@repurposewithai** — a dedicated TikTok account focused on AI-powered content repurposing. The idea: help creators take one piece of content (blog post, podcast, video) and repurpose it across every platform.

## Brand Foundation

### Account Identity

```
Account:   @repurposewithai
Niche:    AI-powered content repurposing
Tone:     Practical, tool-focused, value-first
Audience: Creators, solopreneurs, small business owners
```

### Logo Design Prompt

A detailed prompt was crafted for DALL-E to generate the brand logo:

```
A minimalist mark combining a recycling arrow with an AI spark icon.
Color palette: deep navy (#1a1a2e) and electric blue (#4361ee).
Clean lines, no text, scalable to profile picture size.
Modern, tech-forward, approachable.
```

### Platform Bios

Consistent bios were drafted for every platform:

**TikTok / Instagram / YouTube / Pinterest / Gumroad:**
> Turn one piece of content into 10 — with AI. Tips, tools, and workflows for creators who want to work smarter.

## The Warmup Strategy

For a new TikTok account, jumping straight into posting is a mistake. The warmup plan:

| Phase | Duration | Activity |
|-------|----------|----------|
| **Warmup** | 2-3 weeks | Daily scrolling, liking, following in-niche |
| **Reserve** | Day 1 | Claim same handle on Instagram, YouTube, Pinterest, Gumroad |
| **Post** | Week 3+ | Lead with value content (repurposing tips), not product promotion |

The warmup teaches the algorithm what the account is about before the first post goes live.

## Brand Documentation

All brand assets were documented in a single file:

**`TikTok-Account-Brand.md`** includes:
- Account name and display name
- Bio text with line breaks
- Logo prompt for DALL-E generation
- Visual style guide (colors, fonts, image treatment)
- Content pillars
- Posting cadence

## Key Results

- **Brand identity** defined with name, bio, logo prompt
- **Platform bios** drafted for 5 platforms
- **Warmup plan** structured (2-3 weeks of algorithm training)
- **Account handles** ready to reserve across platforms
- **Brand doc** centralized for easy reference

## Takeaways

1. **Brand before posts.** The account identity must be locked before any content is created.
2. **Warmup is non-negotiable.** A new account posting immediately gets shadowbanned.
3. **Consistent bios build trust.** The same message across platforms reinforces the brand.
4. **Logo prompts are brand assets.** Store them in the brand doc so they're reproducible.
5. **Reserve handles everywhere.** Even if you only use TikTok, own the name on every platform.
